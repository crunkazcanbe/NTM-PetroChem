# NTM PetroChem

A deep **petrochemical & plastics** add-on for **HBM's Nuclear Tech Mod (Cursed / Community Edition)** on
Minecraft 1.12.2: steam cracking, polymerization, alkylation and more — turning oil and gas into plastics, synthetic
fuels and solvents. Early version (0.1.0).

See **[Releases](../../releases)**. MIT licensed. Requires HBM's NTM.
